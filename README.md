# Player-Item Tables

Ez a program a Webfejlesztés nevű egyetemi kurzus teljesítésére készült.

A Backend-et SpringBoot-al, míg a Frontend-et az oktató álltal biztosított React program átalakításával készítettem el.

Ez a program két táblázatot tartalmaz amely egy irányból össze van kötve. Mindkét táblázat csatlakozik egy h2 adatbázishoz.
Mindkét táblázat esetében képesek vagyunk új elemet hozzáadni, módosítani, illetve törölni.
